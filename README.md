# 🧠 Prompt Manager

Um gerenciador de prompts simples e intuitivo desenvolvido durante a trilha **NLW Pocket - Iniciantes**, da Rocketseat.  
O projeto foi construído **apenas com HTML, CSS e JavaScript**, com o objetivo de aplicar fundamentos do desenvolvimento web e explorar o uso de **IA como copiloto de código**.

---

## 🚀 Sobre o projeto

O **Prompt Manager** é uma aplicação que permite criar, visualizar, copiar e gerenciar prompts de forma prática e organizada.  
Ideal para quem utiliza ferramentas de IA (como o ChatGPT ou o GitHub Copilot) e quer manter seus prompts sempre à mão.

A interface foi inspirada em um design moderno e minimalista, com foco em **usabilidade e produtividade**.

---

## 🧩 Tecnologias utilizadas

- **HTML5** → estrutura do projeto
- **CSS3** → estilização e layout responsivo
- **JavaScript (ES6)** → lógica e manipulação de dados no navegador
- **GitHub Copilot** → assistente de IA para acelerar o desenvolvimento
- **Figma MCP** → ferramenta de design e prototipagem
- Outras **ferramentas de IA** foram utilizadas para otimizar código, design e documentação

---

## 💡 Funcionalidades

✅ Criar novos prompts  
✅ Editar e salvar prompts existentes  
✅ Copiar o conteúdo com um clique  
✅ Interface escura moderna  
✅ Armazenamento local (localStorage) — mantém seus prompts salvos no navegador  
✅ Busca por título

---

## 🛠️ Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/guithr/prompt-manager.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd prompt-manager
   ```

3. Abra o arquivo `index.html` diretamente no navegador.

💡 **Não é necessário nenhum servidor ou instalação adicional** — tudo roda 100% no lado do cliente.

## 🎨 Layout

O design do projeto foi criado no **Figma MCP**, com foco em clareza e facilidade de uso.  
O layout segue uma estética escura, com destaque para botões de ação em azul.
